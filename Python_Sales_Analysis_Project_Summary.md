# Sales Data Analysis with Python

## Project overview
A synthetic business-sales project created to demonstrate practical Python skills for data analysis and data quality work.

## Tools
- Python
- Pandas
- Matplotlib

## What the project demonstrates
- Loading and inspecting CSV data
- Missing-value checks
- Duplicate detection
- Data cleaning
- Recalculation and validation of business metrics
- Exploratory data analysis
- Grouping and aggregation
- Data visualization
- Business-oriented insights

## Controlled data-quality issues
The raw dataset contains:
- 2 missing cells
- 1 duplicate Order_ID
These issues are intentionally included so the cleaning process can be demonstrated.

## Cleaning performed
- Missing Region values replaced with "Unknown"
- Missing Sales_Rep values replaced with "Unassigned"
- Duplicate Order_ID removed
- Sales and Profit recalculated
- Profit Margin calculated

## Portfolio visuals
1. Monthly Sales Trend
2. Sales by Category
3. Profit by Region

## Important
The dataset is fully synthetic and does not contain confidential client or employer information.
