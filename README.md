# Python Sales Analysis

## Project Overview

This project demonstrates a data analysis workflow using Python, Pandas, and Matplotlib.

The objective is to clean, validate, analyze, and visualize sales data to identify trends, compare performance, and generate useful business insights.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- CSV
- Data Cleaning
- Data Validation
- Exploratory Data Analysis (EDA)
- Data Visualization

## Project Workflow

The project follows these main steps:

1. Load raw sales data.
2. Inspect the dataset and identify data quality issues.
3. Handle missing values.
4. Identify and remove duplicate records.
5. Validate and recalculate sales metrics.
6. Perform exploratory data analysis.
7. Analyze sales and profit trends.
8. Create visualizations using Matplotlib.
9. Generate clean and organized datasets.

## Data Quality

The raw dataset contained data quality issues that were addressed during the cleaning process, including:

- Missing values
- Duplicate Order IDs
- Data consistency checks
- Recalculation of Sales and Profit metrics
- Validation of Profit Margin

The cleaned dataset was saved separately from the original raw data.
